# Chess Drills

Short chess drills instead of full games. Mobile-first, works on desktop, installable as a PWA.

- **Mate puzzles**: mate in 2, 3, or 5 at easy/medium/hard (300 puzzles per depth, from Lichess).
- **Name that opening**: watch a line play out, pick the opening (or the variation, in hard mode).
- **Opening trainer**: 38 common openings. Learn mode shows each move; Practice mode tests you.
  Five clean practice runs mark a line as memorized.

Progress is saved in the browser's localStorage.

## Development

```sh
npm install
npm run dev        # http://localhost:5173 (add --host to open it on your phone over Wi-Fi)
npm run build      # production build in dist/
```

## Data

`src/data/*.json` is generated by `node scripts/build-data.mjs` (needs `curl` and `zstd`).
It downloads a slice of the [Lichess puzzle database](https://database.lichess.org/#puzzles) and the
[lichess-org/chess-openings](https://github.com/lichess-org/chess-openings) names (both CC0),
checks every puzzle ends in mate and every trainer line is legal, and names each line from the dataset.
To add or change trainer openings, edit `scripts/openings-source.mjs` and re-run the script.

`src/data/opening-stats.json` (the popularity/results tags in the trainer) is generated by
`node scripts/build-stats.mjs` from a ~300MB slice of a monthly
[Lichess rated-games dump](https://database.lichess.org/#standard_games). Bullet games are excluded;
"club" means 1200–1999 average rating and "strong" means 2200+. Run it after `build-data.mjs`.
